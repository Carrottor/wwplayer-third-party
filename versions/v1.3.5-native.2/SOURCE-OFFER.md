# 对应源码提供

当前发行版所包含的相关第三方组件完整对应源码，以及其修改补丁和必要
构建材料，可通过随包 `SOURCE-RELEASE.json` 中的公开地址免费取得。
各组件继续适用其原始许可证；收到源码的用户可以行使这些许可证授予的
修改、再分发及其他权利，不附加保密条件。

公开维护与源码获取联系入口：
https://github.com/Carrottor/wwplayer-third-party/issues

如果对应版本的下载入口无法访问，或发现源文件及构建材料缺失，请通过
该入口提出源码获取请求。WWPlayer 将按适用许可证提供相应材料；通过
网络下载不收费，其他交付方式的费用不超过实际分发成本。
对采用书面要约满足源码提供条件的组件，该要约自包含此声明的发行版
最后一次分发起至少三年有效。

此源码提供范围针对实际分发的第三方组件，不包含与之无关的 WWPlayer
自有程序代码、商标、账户凭据或用户媒体。
